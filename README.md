📝 Character Counter
A clean and responsive real-time character counter web application. Users can type or paste text into the input field to instantly track total character counts with zero latency.

🔗 Live Demo: https://123parwithkhon.github.io/character-counter-js/

🚀 Features
- Real-time character counting on every keystroke or text paste.
- Dark mode aesthetic styled with a modern palette (#0a192f) and custom typography (Poppins).
- Clean card interface with disabled manual textarea resizing for consistent layout presentation.

🛠 Technologies Used
- HTML5 (Textarea input fields, semantic container elements)
- CSS3 (Absolute centering, dark theme styling, custom input states)
- JavaScript (String length calculation, dynamic input event listeners, live DOM updates)

💻 How to Run
1. Clone or download this repository:
   git clone https://github.com/123Parwithkhon/character-counter-js.git
2. Navigate to the project folder:
   cd character-counter-js
3. Open index.html in any web browser.

📝 Счетчик символов
Удобное и понятное веб-приложение для мгновенного подсчета количества символов в реальном времени. При вводе или вставке текста в поле результат автоматически рассчитывается без задержек.

🔗 Демо: https://123parwithkhon.github.io/character-counter-js/

🚀 Особенности
- Подсчет символов в реальном времени при каждом нажатии клавиши или вставке текста.
- Эстетичная темная тема в современных тонах (#0a192f) и аккуратная типографика (Poppins).
- Минималистичный интерфейс с фиксированным текстовым блоком для сохранения единого стиля.

🛠 Используемые технологии
- HTML5 (многострочное поле ввода textarea, семантическая структура)
- CSS3 (абсолютное центрирование, стилизация темной темы, отступы)
- JavaScript (подсчет длины строки length, обработка событий input, динамическое обновление текста в DOM)

💻 Как запустить
1. Клонируйте или скачайте этот репозиторий:
   git clone https://github.com/123Parwithkhon/character-counter-js.git
2. Перейдите в папку проекта:
   cd character-counter-js
3. Откройте файл index.html в любом веб-браузере.
